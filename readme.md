**Эскизный проект мобильного приложения для PMSYS**

## Общая информация

**Название:** PMSYS Mobile
**Цель:** Обеспечить доступ к системе управления проектами PMSYS и оповещение пользователей о возникновении инцидентов.
**Целевая аудитория:** Руководители проектов и разработчики, ответственные за эксплуатацию системы.
