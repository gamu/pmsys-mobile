## **Анализ вариантов использования**

### 1. Авторизация пользователей
- Пользователь вводит логин и пароль.
- Проверка учетных данных через систему аутентификации PMSYS.
- Генерация и выдача JWT-токена для дальнейших запросов.

### 2. Работа с инцидентами
- Получение списка инцидентов (с фильтрацией по статусу, ответственным, дате).
- Получение деталей инцидента (описание, вложения, дэдлайн, ответственный).
- Обновление статуса инцидента (принятие, отклонение).

### 3. Оповещения
- Отправка push-уведомлений о новых инцидентах или статусе текущих инцидентов.

### 4. Планирование работ
- Получение плана работ на месяц.
- Внесение информации о выполненных задачах.
